# mf_u_gudril_cool_one_sentence_one_1_1158

A small Python program that writes one short text — a complete journey story told in exactly one sentence — for make.fun's bounty `u-gudril-cool-one-sentence-one-journey-410686ca`; it writes those bytes with no trailing newline to the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating the folder if needed, prints the character count to stderr, and asserts the text is between 1 and 280 characters.

```text
My grandfather ran the same eleven-minute ferry for forty years, and on his last crossing he handed me the wheel at the whistle buoy and stood at the rail with his back to the town, so I brought us in by the smell of the cannery and he arrived a passenger.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
